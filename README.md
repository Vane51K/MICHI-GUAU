# ☕🐾 Michi & Guau Café

Sitio web desarrollado como práctica para aprender los fundamentos de **HTML5** y **CSS3**.

El proyecto consiste en la creación de una página web para una cafetería temática donde los visitantes pueden disfrutar de café mientras conocen perros y gatos disponibles para adopción.

---

## 📌 Descripción

La página incluye una estructura semántica en HTML y estilos básicos en CSS para crear una interfaz sencilla, agradable y fácil de navegar.

## ✨ Características

- Estructura semántica con HTML5.
- Diseño sencillo utilizando CSS3.
- Menú de navegación.
- Sección de bienvenida.
- Menú de bebidas y postres.
- Sección de mascotas en adopción.
- Lista de beneficios del café.
- Formulario de contacto.
- Pie de página con información básica.

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Visual Studio Code

## 🚀 Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo **index.html** en cualquier navegador web.
