# 📖 Descripción

**Michi & Guau Café** es una página web creada como proyecto académico para practicar el uso de **HTML5** y **CSS3**.

La temática del sitio es una cafetería donde las personas pueden disfrutar de café y postres mientras conocen perros y gatos disponibles para adopción, promoviendo el amor por los animales y la adopción responsable.

---

# ✨ Características

- ☕ Página de inicio con bienvenida.
- 🐾 Sección de mascotas en adopción.
- 🍰 Menú de bebidas y postres.
- ❤️ Información sobre la cafetería.
- 📩 Formulario de contacto.
- 📱 Diseño limpio y sencillo.
- 🎨 Estilos realizados con CSS3.

# 🎯 Objetivo del proyecto

Este proyecto tiene como finalidad poner en práctica los conocimientos básicos de desarrollo web utilizando HTML y CSS.

Durante su desarrollo se aplicaron conceptos como:

- Estructura semántica.
- Etiquetas HTML.
- Enlaces.
- Imágenes.
- Formularios.
- Listas.
- Selectores CSS.
- Colores.
- Tipografías.
- Flexbox.
- Efectos Hover.
- Organización de archivos.
